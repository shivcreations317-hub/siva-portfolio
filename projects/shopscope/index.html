How this was built

From raw e-commerce extract to a customer decision surface

SQL · Python · Power BI

The brief

NovaCart, a D2C lifestyle brand, was growing revenue but could not explain why customers were not coming back. Sales, returns and customer data lived in separate extracts.

Goal: measure sales quality, find repeat-customer drivers, and quantify the retention and returns opportunity.

The build

Modelled a star schema (orders → customers → products → returns), validated the extract, built RFM segments and cohort retention in Python, then wrote the SQL layer for the same metrics.

The Power BI build kit includes the data model, DAX measures and theme used for the report version.

SQL Server Python Pandas Power BI DAX

The outcome

40.1% of customers repeat, but the top two RFM segments drive 49.0% of net revenue. Returns sit at 14.5%, with size/fit the largest reason.

Recommendations: fix size guidance in apparel/footwear, run a win-back play for the At Risk segment, and protect the Champions cohort with early access.
